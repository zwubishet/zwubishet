## 🛠️ What I'm Building

### 🏫 EduManage OS — SaaS School Management System
A production-ready multi-tenant platform for schools with role-based access (Super Admin, School Admin, Teacher).

**Stack:** React 19 · Node.js/Express · Hasura GraphQL · PostgreSQL · Redis · TailwindCSS · Apollo Client · Docker

**Features:**
- Multi-tenant architecture with school-scoped data isolation
- JWT auth with Hasura claims, Redis token blacklisting
- Real-time dashboards via GraphQL subscriptions
- Academic cycle management (years → terms → grades → sections → classes)
- Teacher assignment, student enrollment with capacity checks
- Exam management, mark entry, GPA calculation engine
- Attendance tracking per section
